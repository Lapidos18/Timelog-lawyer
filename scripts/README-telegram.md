# Напоминания о сроках в Телеграм

Раз в сутки приложение присылает в Телеграм список того, что горит:
просроченное, сегодняшнее и ближайшее — каждое событие показывается тогда,
когда до него осталось не больше его собственного «предупредить за N дней».
Если напоминать не о чем, сообщение не отправляется вовсе.

Запускается расписанием Vercel (`vercel.json`) в 01:00 UTC — это 08:00 по
Новосибирску. Проверить в любой момент можно кнопкой **«Проверить
напоминание»** в разделе «Сроки и заседания».

---

## Шаг 1. Создать бота

1. В Телеграме найдите **@BotFather** и отправьте ему `/newbot`.
2. Он спросит имя (любое, например `Тайм-трекер напоминания`) и логин бота —
   логин должен заканчиваться на `bot`, например `ak_buhmin_reminder_bot`.
3. В ответ придёт **токен** вида `1234567890:AA...`. Это пароль от бота:
   в переписку его не вставлять, хранить только в настройках Vercel.
4. **Откройте своего бота и нажмите «Запустить» (Start).** Без этого
   Телеграм запрещает боту писать первым, и сообщения не дойдут.

## Шаг 2. Узнать идентификатор чата

Найдите в Телеграме бота **@userinfobot**, отправьте ему любое сообщение —
он ответит вашим числовым `Id`. Это и есть идентификатор чата.

## Шаг 3. Прописать переменные в Vercel

Проект `timelog-lawyer` → **Settings → Environment Variables**. Добавьте
четыре переменные для окружения **Production**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_ID` | число из @userinfobot |
| `SUPABASE_SERVICE_ROLE_KEY` | служебный ключ Supabase (Project Settings → API Keys → `service_role`) |
| `CRON_SECRET` | любая длинная случайная строка, придуманная вами |

Зачем служебный ключ: у задания по расписанию нет входа в приложение, а
правила доступа к базе без входа не отдают ничего.

Зачем `CRON_SECRET`: Vercel подставляет его в заголовок при запуске по
расписанию, и по нему приложение отличает «свой» вызов от чужого. Без этого
адрес `/api/notify` был бы открыт всему интернету, и написать в ваш чат мог
бы любой желающий.

После добавления переменных нужен **повторный деплой**: Deployments →
у последней сборки → **Redeploy**. Переменные подхватываются только при
сборке.

## Шаг 4. Проверить

Раздел «Сроки и заседания» → **«Проверить напоминание»**. Возможные ответы:

- «Отправлено в Телеграм» — всё работает;
- «Напоминать не о чем» — ближайших и просроченных событий нет, это не ошибка;
- сообщение об ошибке — в нём написано, чего не хватает.

---

## Если сообщения перестали приходить

- Проверьте кнопкой «Проверить напоминание» — она покажет причину.
- `Forbidden: bot was blocked by the user` — бот заблокирован в Телеграме.
- `chat not found` — неверный `TELEGRAM_CHAT_ID` либо вы не нажали «Запустить»
  в переписке с ботом.
- Расписание Vercel видно в проекте → **Settings → Cron Jobs**, там же
  последний запуск и его результат.
